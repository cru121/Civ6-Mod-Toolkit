Civ6 Mod Toolkit
Install Usage Safety GitHub

Manage your Civ VI mods without starting the game

A small Windows tool for Sid Meier's Civilization VI. It opens in your browser. You can turn mods and DLC on and off, and add or remove mods in a saved game configuration without setting it up again.

Download v1.0.0
Windows 10 or 11 · needs Node.js 22.5+ · All releases

Dashboard

Shows your Workshop and local mods, saved configurations, official DLC, whether the game is running, and which folders the toolkit uses.

Mod manager

Turn mods and DLC on or off, with warnings about missing dependencies and conflicts. Useful when a broken mod stops the game from starting.

Config editor

Add or remove mods in an existing .Civ6Cfg. Your other game settings stay as they are.

Install and run

  1. Download the zip using the button above.
  2. Unblock it (recommended): right-click the zip → Properties → tick Unblock → OK. If you skip this step, Windows may show "Windows protected your PC". If it does, click More info → Run anyway.
  3. Extract the zip to any folder, such as Documents.
  4. Double-click Civ6 Mod Toolkit.cmd. The toolkit opens in your browser.

The toolkit needs Node.js 22.5 or newer. If it's missing or out of date, the launcher can install it for you with Windows' built-in winget, or open the download page.

While the toolkit runs, a small window stays open. Press O to open the toolkit in your browser again, R to restart it, or S to stop it. Closing the window also stops the toolkit.

From source

npm install
npm start

Then open http://127.0.0.1:8673.

Usage

Dashboard

The toolkit finds your mod folders, configurations folder and the game's Mods.sqlite database automatically. If one shows not found, click Edit paths. If you just installed a mod, start Civ6 once so the game registers it.

Mod manager

  1. Filter by Workshop, Local or Official DLC, by enabled or disabled, or by name.
  2. Tick or untick mods, or switch to Two panes and click mods to move them between Available and Enabled.
  3. Click i on a mod to see its details, dependencies, conflicts, and which of your configurations use it.
  4. Click Apply changes. Civ6 must be closed first.

Config editor

  1. Pick a configuration file.
  2. Untick mods on the left to remove them, and tick installed mods on the right to add them.
  3. Choose Save (overwrite + backup) or Save as new file….
  4. In the game, go to Single Player → Create Game and load the configuration.

Safety

  • Before it overwrites a file, the toolkit saves a timestamped backup (.bak-…).
  • It changes only the mod list in a configuration, and checks the result before writing. If the check fails, nothing is written.
  • It changes the mod database only while Civ6 is closed. It changes only the enabled/disabled flags, and restores the backup if the result looks wrong.
  • It listens only on 127.0.0.1, and accepts requests only from its own page.
